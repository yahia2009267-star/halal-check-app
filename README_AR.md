# Halal Check — نسخة البداية

## ما الموجود الآن؟
- واجهة عربية/إيطالية قابلة للتبديل.
- أقسام مستقلة: الفحص الشامل، فحص الحلال، الأسعار، المساعد الذكي، السجل، المفضلة.
- بحث باركود عبر قاعدة Open Food Facts عند توفر البيانات والاتصال.
- مسح مباشر للباركود إذا كان المتصفح يدعم `BarcodeDetector` ويعمل الموقع عبر HTTPS.
- OCR تجريبي لقراءة ملصق المكونات عبر Tesseract.js؛ يجب مراجعة النص المستخرج يدويًا.
- تحليل أولي بالكلمات المفتاحية فقط؛ ليس فتوى ولا شهادة حلال.
- سجل ومفضلة محفوظان محليًا على الجهاز.
- روابط بحث أسعار في الويب؛ **لا توجد أسعار محلية مباشرة أو مؤكدة في هذه النسخة**.
- واجهة المساعد تحاول الاتصال بـ `/api/ai`، لكنها ستوضح أن الخدمة غير مهيأة ما لم تنشر الخادم وتضبط مزوّد الذكاء الاصطناعي.

## النشر المجاني للواجهة على GitHub Pages
1. أنشئ مستودع GitHub جديدًا، مثل `halal-check-app`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع: `index.html`, `manifest.json`, `sw.js`, `icon.svg`, `README_AR.md` ومجلد `worker`.
3. افتح **Settings → Pages** واختر النشر من الفرع `main` والمجلد `/(root)`.
4. افتح رابط Pages بعد اكتمال النشر. السماح بالكاميرا يحتاج HTTPS، ويوفره GitHub Pages.

## إعداد الذكاء الاصطناعي بأمان (اختياري، غير مفعّل تلقائيًا)
الواجهة الثابتة على GitHub Pages لا تخفي مفاتيح API. لا تضف المفتاح إلى `index.html` ولا إلى مستودع عام.

1. أنشئ Worker في Cloudflare، وانشر `worker/index.js` ككود الخادم.
2. اضبط مسارًا يتيح للواجهة الاتصال بـ `/api/ai` على النطاق نفسه، أو عدّل عنوان `fetch('/api/ai')` إلى عنوان Worker المخصص بعد إعداد CORS المقيّد على نطاقك.
3. في إعدادات Worker، أضف `AI_API_KEY` كـ **Secret**، وأضف المتغيرين `AI_API_URL` و`AI_MODEL` وفق مزود متوافق مع واجهة OpenAI Chat Completions.
4. أضف حدًا للاستخدام أو حماية من الإساءة قبل مشاركة الرابط علنًا. المثال لا يطبق تسجيل دخولًا أو حصة مستخدمين.
5. اختبر طلبًا صحيحًا وخاطئًا، وفشل المزوّد، وحدود الطلب، ولا تعتبر التكامل جاهزًا قبل نجاح الاختبارات.

**ملاحظة مهمة:** مثال Worker قالب تقني غير مربوط بمزوّد بعينه ولم يُختبر بمفتاح حقيقي. لن يعمل الذكاء الاصطناعي حتى تُعدّ متغيراته وتنشره وتختبره. تأكد من شروط الخصوصية والاحتفاظ بالبيانات لدى المزوّد الذي تختاره.

## الحدود الحالية
- Open Food Facts قد لا يحتوي على المنتج أو مكوناته، وقد تكون البيانات قديمة.
- تحليل الحلال يعتمد على كلمات مفتاحية بسيطة ولا يحدد مصدر كل مكوّن.
- أسعار المتاجر لا تُجلب آليًا في هذه النسخة؛ الروابط تفتح بحثًا خارجيًا فقط.
- OCR يعتمد على تحميل مكتبة خارجية من CDN عند الاتصال بالإنترنت.
- السجل والمفضلة محليان في المتصفح وليسا متزامنين بين الأجهزة.
